# agy-meme 表情

用户发来 `:表情名:` 或 `[表情: 表情名]` 时，可用 agy-meme 的 get_sticker 查询名称和含义，自然接话。已知表情只需暗号。适合回表情时，用 search 找图，调用 get_sticker 后原样输出 reply 中的 Markdown；一次至多一张。需要看图时使用 original。

用户明确说“收藏这张图”时，用 collect 收录这次指明的图片。根据用户说明或实际看过的画面填写含义。仅有附件显示名、无法取得已确认的本地文件时，让用户在 🐱 图库选择原图，或提供该图的本地路径。多张候选而指代不明时请用户指定。

发贴图时保留 reply 自带的图片标记和原图地址。旧规则中引用的 compact 横幅不用于新回复。
